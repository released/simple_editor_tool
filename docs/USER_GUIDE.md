# Simple Editor Tool 使用指南

## 文檔編輯與比較工具

下列功能位於 **檢閱 / Review** 選單。完整支援範圍與限制請參閱
[Document editing and comparison](DOCUMENT_EDITING_COMPARISON.md)。

- 左、右、Base 可各自選擇解碼；按「比較」後顯示實際編碼、BOM 及原始換行種類。
  交換左右來源時也會交換其解碼設定；輸出初始採用左側編碼。
- 在雙向檔案比較的左右來源各選一個原始行，再執行「對齊選取的來源行」並重新比較。
  「管理對齊點」可移除配對；全部移除並重新比較後恢復一般合併編輯。
  最多 128 組嚴格遞增配對；顯示空隙不算來源行，有對齊點時輸出唯讀。
- 在資料夾結果選取 1–128 列後執行「重新整理選取的資料夾列」，只更新選取的檔案或子樹。
  其餘列標示「未重新掃描」。複製這些舊列、全部同步、政策同步或建立基準前需完整比較。
  修改根目錄、遞迴、排除或比較規則後也需完整比較。
- 選取 Text 文字後執行「比較選取文字與剪貼簿」，會建立新的貼上文字比較分頁。
  每側上限為 UTF-8 16 MiB／200,000 行；不裁切超量內容，不影響其他分頁、草稿或 Undo。
  貼上內容不寫入工作區 INI。
- 「選擇語法模式」可覆蓋一般文字檔與分割檢視的語法；「副檔名語法對應」可設定
  `.conf=JSON`、`.inc=C/C++` 等對應。Automatic 恢復自動判斷，Plain text 停用語法。
  對應儲存於偏好設定，個別覆蓋隨明確儲存的工作區保留；不修改文字、編碼或 Undo。
- C/C++ 模式下的「C/C++ 函式大綱」可跳到辨識到的定義。這是有限啟發式分析，非完整編譯器；
  巨集、lambda、複雜建構子／運算子／樣板宣告可能省略或判斷不完整。
  上限為 32 MiB、100 萬 token、1,024 層大括號、4,096 個定義；編輯後舊結果失效。
- 從資料夾比較開啟的檔案配對，可使用「上一個差異檔案」、「下一個差異檔案」、
  「返回上層資料夾比較」。依父分頁目前可見順序導覽，不循環；既有子分頁草稿保留。
  父結果重新掃描或關閉後不使用舊導覽狀態。
- 「註解選取的差異」可替雙向／三方文字差異區塊加入註解與已檢閱狀態；已檢閱不代表衝突已解決。
  使用「儲存／載入檢閱註解」明確存取 `.setreview`；來源指紋不符時拒絕載入並保留既有註解。
  比較變更時舊註解保留供儲存或明確清除，不自動附到新來源。最多 1,024 區塊，每則 4,096 UTF-16
  code units。一般關閉會詢問未儲存註解；工作區與當機復原不包含未儲存註解。
- 「匯出含註解的 HTML」包含完整 Base／左右來源與註解，請明確選擇另一個輸出檔。
  註解中繼資料只有指紋／註解，不含來源緩衝區；兩者都禁止覆寫來源路徑與硬連結。

大型文字分頁檢視另有「尋找」、「找下一個」、`Ctrl+F` 與 `F3`。
UTF-8／UTF-16 LE／BE 使用串流、區分大小寫的精確文字搜尋，查詢長度為 1–4,096 UTF-16
code units，可跨讀取區塊。Ctrl+F 從目前頁開始，F3 繼續到檔尾且不循環；Esc 取消並保留目前頁。
此分頁檢視不支援正規表示式、取代或傳統字碼頁搜尋。一般滾輪捲動，Ctrl+滾輪縮放。

[English user guide](USER_GUIDE_EN.md)

Simple Editor Tool 是 Windows x64 原生桌面工具，用於編輯文字與十六進位資料、
比較二進位檔案與原始碼、三方合併，以及比較與同步資料夾。程式使用靜態連結的
MFC／C++ 執行階段，不需另外安裝 Python、.NET、驅動程式或編輯器外掛。

## 1. 啟動與語系

將 `SimpleEditorTool.exe`、`lang_en.ini`、`lang_tw.ini` 放在同一資料夾，直接執行 EXE。
首次啟動預設為繁體中文。選擇 **語系 / Language → English** 或 **繁體中文** 即可切換；
已儲存的語系偏好優先於預設值，下次啟動會沿用。

切換會更新已建立的介面文字，保留文件、草稿、游標、選取範圍與 Undo。
語系名稱與選項不會改變檔案編碼。文件內容、檔案路徑、搜尋字串、程式語法、
資料格式識別字與第三方授權原文不會被翻譯。未收錄的診斷內容保留英文。
Windows 原生選檔、字型及部分系統按鈕仍由 Windows 語系決定。

語系檔使用 UTF-8，來源版本位於 `src/res`，發佈版本位於 EXE 旁。`[Language]`
包含版本、語系代碼與名稱；`[Strings]` 的固定識別鍵對應顯示文字。值內支援
`\n`、`\r`、`\t`、`\\`。請保留鍵名、格式參數及 `{0}` 等訊息參數。
修改後重新啟動才會重新載入語系檔。檔案遺失、損毀或不相容時會使用可操作的
英文介面；修復兩份語系檔後再重新啟動。只有 EXE 時也能使用英文備援介面。

## 2. 開啟檔案與分頁

選擇 **開啟檔案…**、按 `Ctrl+O`，或將一個／多個檔案拖入主視窗。
每個檔案保留在獨立工作區分頁；開啟新檔案不會取代舊檔案，再次開啟相同路徑會
切回原分頁。可解碼且不超過限制的文字預設開啟在「文字」，二進位或大型檔案使用
「十六進位」。應用程式啟動時最大化。

**新增文字檔** 與 **從 Unicode 剪貼簿新增** 會建立未命名文件，第一次儲存使用另存新檔。
可用分頁右鍵選單、滑鼠中鍵、`Ctrl+W` 關閉指定分頁；有未儲存內容時會先詢問。
右鍵選單另有關閉其他／左側／右側分頁與移動分頁。拖曳分頁可調整順序。
最近開啟及重新開啟已關閉檔案位於檔案選單。

同一 Windows 工作階段只顯示一個正常主視窗。再次啟動 EXE 時，命令列指定的檔案
會轉送至既有視窗，不會丟棄其草稿：

```powershell
.\SimpleEditorTool.exe "first.bin" "notes.md"
```

## 3. 文字編輯

支援 UTF-8、UTF-16 LE／BE、Big5／CP950 與 Windows 系統編碼。可在編碼選單指定來源編碼。
顯示與編輯會保留來源換行風格；**轉換輸出編碼／換行並另存副本…** 可另存指定編碼、
BOM 與 CRLF／LF／CR，不會直接覆寫原始檔案，無法無損轉換時會拒絕。

文字檢視提供行號、語法色彩、Markdown 標題／強調／連結／程式碼色彩、書籤、摺疊、
空白與換行符號、自動換行、多重選取及欄位選取。預設深色內容底色為 `#3F3F3F`，
偏好設定可選淺色、深色或系統對比色彩。

檢視選單可設定字型、Tab 寬度、排序行、去除重複行／空白行及行尾空白，並可啟用
共用文字雙視窗。雙視窗共用同一草稿、Undo 與儲存狀態，游標與捲動位置獨立。
單字完成來自目前文件與內建語言字詞，不是語意程式分析器。

EditorConfig 支援文件縮排設定與手動覆寫；不會因載入設定而重新排版文件。
`Ctrl+G` 可跳至行，**Markdown 大綱…** 可依標題導覽。
檢閱選單提供三種文字標記色彩；標記不改變內容，編輯後會清除舊標記。

## 4. 尋找與取代

`Ctrl+F` 與 `Ctrl+H` 開啟同一個尋找／取代視窗，可選「目前文件」或
「全部開啟的文字文件（包含未儲存）」。後者包含未命名草稿，會略過二進位或超過
文字限制的檔案；不包含比較來源窗格。比較窗格使用目前文件範圍。

支援一般文字、跳脫序列、單行 Scintilla POSIX 正規表示式、大小寫、完整單字、
往前／往後、選取範圍、循環、計數與列出全部結果。多行一般文字可直接貼入專用欄位。
跳脫序列可使用 `\n`、`\r`、`\t`、`\xHH`、`\uHHHH`、`\\`；
正規表示式擷取取代使用 `\1` 至 `\9`，不是任意跨行正規表示式引擎。

「全部取代」每個文件建立一個 Undo，不會自動儲存。跨文件取代可先預覽並選擇文件；
參與文件唯讀、忙碌、已關閉或版本改變時，過期規劃不會直接套用。
`F3`／`Shift+F3` 重複尋找；列出的結果可按兩下定位。

`Ctrl+Shift+F` 可搜尋已開啟草稿或磁碟資料夾。結果列出路徑、行號／位址與預覽。
資料夾批次取代提供預覽、版本檢查、備份與日誌，不會改寫開啟中的未儲存草稿。
詳見 [多檔搜尋](MULTI_FILE_SEARCH.md)。

## 5. 十六進位編輯與定位

十六進位檢視顯示實體位移、位元組及 ASCII／解碼字元。可選每行 8／16／32 位元組、
群組大小及顯示基底位址。顯示基底不會改變實體檔案位移。

拖曳或以 Shift＋方向鍵選取；`Ctrl+C` 複製十六進位文字與原始位元組，`Ctrl+X` 剪下。
`Ctrl+V` 依目前模式插入或覆寫；右鍵選單可明確指定貼上模式與 UTF-8 文字貼上。
點選 ASCII 欄或按 Tab 切換輸入欄，Ins 切換插入／覆寫。可新增、刪除、修改位元組並復原／重做。

`Ctrl+G` 使用十六進位位址，例如 `0x100`，或 `d:256` 指定十進位，亦可跳至檔尾。
位元組搜尋支援精確資料、`AA ?F ??` 萬用樣式，以及 `u32le:1234`、`i16be:-2`、
`f32le:1.5` 等型別數值。數值取代以十六進位位元組表示。

檢閱選單可將目前選取範圍在文字／十六進位間定位，包含 BOM 與原始換行。
半個多位元組字元、部分代理對、BOM 專屬位元組及虛擬換行的半部會被拒絕。
具名彩色範圍書籤可協助記錄位址；修改檢閱可查看草稿相對磁碟的差異。

## 6. 檔案比較與直接貼上比較

選擇 **比較檔案…**，在左右路徑欄輸入路徑、使用瀏覽按鈕或開啟檔案下拉清單，
選取模式並按「比較」。「交換左右」後需重新比較。

| 模式 | 用途 |
| --- | --- |
| 十六進位：相同位址 | 比較相同實體位移的位元組。 |
| 十六進位：辨識插入與刪除 | 在附近插入／刪除後重新對齊。 |
| 文字／原始碼（雙向） | 對齊行並產生可編輯的合併輸出。 |
| 貼上文字（雙向） | 將文字 A／B 直接貼入左右欄，不需先存成檔案。 |
| 文字合併（三方） | 依共同 Base 合併左右版本並檢閱衝突。 |
| 資料夾／同步 | 比較資料夾並規劃同步。 |
| CSV／TSV／JSON | 唯讀的結構化資料比較。 |

比較已開啟的檔案時會採用目前草稿快照；其他來源從磁碟讀取。
來源窗格為唯讀，合併輸出獨立。比較本身不會修改輸入檔案。
二進位差異列出兩側位址與值；按兩下或使用 `F7`／`Shift+F7` 定位。
可拖曳分隔線，調整窗格比例。區段設定可指定不同起點與忽略實體區段。

貼上比較的左右欄可輸入、選取、Undo／Redo；空白一側也有效。編輯會使舊結果失效。
貼上草稿保留於目前工作階段，不會寫入工作區 INI；關閉前會詢問是否捨棄。
「儲存結果」只寫入指定輸出，貼上比較預設使用 UTF-8。

## 7. 文字合併與差異檢閱

可忽略空白、大小寫或換行差異，篩選變更／衝突，選取區塊後採用左側、右側、兩側，
三方模式另可採用 Base。獨立變更自動合併；重疊變更顯示衝突標記。
可直接編輯輸出，移除標記後明確標記手動結果已解決；再次編輯需重新確認。
未解決衝突預設不可儲存，除非明確啟用允許未解決標記。

完整來源提供字元差異、原始行號、同步捲動與顯示用空白對齊。對齊來源不啟用換行或摺疊，
以維持列對應；文字與貼上輸入仍有各自的檢視設定。三方比較可顯示／隱藏完整 Base。
字元細節限每行前 8,192 個 UTF-16 單位及既有計算預算，完整長行仍可讀取與搜尋。
未標記的超出範圍不代表內容相同。

另有相似行對齊、精確唯一移動區塊、未變更前後文摺疊，以及唯讀的手動行錨點。
文字規則支援一般文字忽略與時間戳遮罩，不會改寫來源。具名比較預設集可明確儲存、
套用或刪除；套用不會自行比較或同步。詳見 [比較與檢查工具](WORKFLOW_EXPANSION.md)。

## 8. 外部變更與安全儲存

`Ctrl+S` 儲存目前檔案；另存新檔可選另一個目的地。儲存在背景進行，替換前可取消。
進行儲存時會暫停該文件的修改，但仍可捲動、縮放、切換其他分頁。
已完成的原子替換不會因稍後才收到取消而被假裝撤銷。

磁碟來源變更時，文字草稿仍保留，通知提供「保留草稿」、「與磁碟比較」及「重新載入」。
保留只關閉同一磁碟版本的提示。比較會開啟獨立唯讀快照；重新載入沿用未儲存變更確認。
來源識別、大小、修改時間不符時，依賴舊來源的讀取或儲存會被拒絕。
失敗或取消不應視為已儲存；請保留草稿，確認來源後重新載入或另存。

## 9. 資料夾比較與同步

選取左右資料夾，可包含子資料夾，並使用分號分隔的包含／排除萬用規則。
可依內容、大小、大小／時間或 SHA-256 比較；大小／時間相同不保證位元組相同。
可排序、依狀態篩選或切換樹狀結果，按兩下檔案配對可另開比較分頁。
獨立文字規則可補充原始位元組結果，但不會改變同步的原始資料意義。

同步必須先預覽。更新會保留目標獨有檔案；鏡像會將目標獨有資料移至備份。
可選較新檔案或基準雙向策略；雙方都修改時會顯示衝突，依基準傳遞刪除需明確啟用。
可略過個別項目／子樹，影響中的開啟檔案有草稿或忙碌時會阻擋作業。

備份存放於目標的 `.SimpleEditorTool.backups/<operation>/data/`，比較掃描會排除此位置。
取消或錯誤可能保留已完成的操作，不提供自動整批回滾。請依回報的日誌使用重試或復原預覽。
同步拒絕重解析點、重疊根目錄與檔案／資料夾型別衝突。
詳見 [資料夾比較與復原](FOLDER_COMPARE_AND_RECOVERY.md)。

## 10. CSV、TSV 與 JSON

CSV／TSV 可解析引號與多行欄位，並設定標頭、欄位配對、識別鍵與精確十進位容許差。
重複識別鍵會回報無法明確配對。留空規則時按位置比較。

JSON 比較忽略物件鍵順序及排版，保留型別與精確十進位值。
可用 `ignore /metadata/generatedAt` 忽略子樹，或 `key /devices /id` 配對陣列元素。
指標採 RFC 6901，`~1` 表示 `/`、`~0` 表示 `~`；含空白者需加引號。
識別鍵必須為唯一字串或數值，數值 `1` 與字串 `"1"` 不同。缺少／重複鍵會拒絕比較，
未設定的陣列維持位置順序。不支援以識別鍵排序陣列下的歧義子路徑或巢狀排序規則。
這些模式為唯讀，不會自行轉存、同步或修改原始資料。

## 11. 位元組分析與轉換

工具可計算選取範圍或整個檔案的 CRC32、SHA-256、位元組分布與 Shannon 熵值。
互動圖表可點選頻率長條，或選取熵值區塊後定位其實體位元組範圍。
統計來源改變時會拒絕過期定位。

數值檢查器支援大小端序整數與浮點數；可寫入的固定寬度型別使用一個 Undo。
ULEB128／SLEB128 為獨立於端序的唯讀 64 位元解碼，最多讀取 10 位元組，會檢查溢位與檔尾。
具名位元欄位可選取位元範圍修改，保留其他位元。

Base64／十六進位／UTF-8 轉換先選輸入與輸出格式，再預覽。
十六進位僅接受位元組與空白，不接受位址或 `0x`；Base64 使用標準字元與正確 `=` 填補；
UTF-8 必須有效且無 NUL。預覽只顯示前 64 KiB，複製會包含完整格式化輸出。
若從可編輯檔案的十六進位選取範圍開啟，可明確套用「解碼後位元組」，
取代原先範圍並建立一個 Undo；此操作不會儲存。

另有擷取／C 陣列匯出、重複填入、反相、字組交換、反轉、檔案分割／合併、
字串擷取、具名／自訂 CRC 及固定寬度無號整數操作。位址、端序及操作範圍請先確認。

## 12. 二進位範本與韌體檔案

`.settpl` 範本每行使用 `path type offset [decimal-count [stride]]`，例如：

```text
header.version u16le 4
header.flags u16be 6
entries[].value u32le 20 4 8
```

位移／步長預設為十六進位，`d:` 指定十進位；可用整數、浮點、位元組及固定長度文字型別。
樹狀欄位可定位有效的實體範圍。範本唯讀，不執行腳本、運算式或自動載入程式碼；
不相容於 ImHex Pattern Language。詳見 [二進位範本](BINARY_TEMPLATES.md)。

Intel HEX／Motorola S-record 工具可檢查紀錄檢查碼、位址重疊與終止紀錄，並與 BIN 互轉。
稀疏資料轉 BIN 時需選間隙填入值與基底，BIN 本身不保存起始執行位址等紀錄中繼資料。
輸出需與輸入分開。這些功能只處理檔案，不燒錄裝置、不安裝驅動，也不代表實板驗證。
詳見 [韌體格式](FIRMWARE_FORMATS.md)。

## 13. 報告與修補檔

可匯出二進位 CSV／TSV／HTML，以及文字 HTML／摘要／統一差異修補檔。
二進位報告可串流輸出超過畫面列數上限的差異。目的地不能覆寫輸入或其硬連結。
文字修補先檢查來源雜湊（若有）、位置與前後文，再預覽並以一個 Undo 套用；儲存另行執行。

IPS／IPS32 匯入／匯出目前限等長資料，匯入需提供預期 Base SHA-256。
不支援的位址、檢查不符或過期預覽會拒絕套用，輸入檔案不會自動被覆寫。
詳見 [文字報告與修補](TEXT_REPORTS_AND_PATCHES.md) 及 [文字檢閱](EDITOR_REVIEW.md)。

## 14. 工作區、復原與記錄檔

工作區 INI 儲存路徑、檢視、比較規則、縮放與位址標註，不包含未儲存文件／合併內容。
載入會保留既有分頁及草稿，比較需再次明確執行；貼上比較不寫入工作區。
偏好設定可選啟動時還原與獨立草稿快照。復原會開啟未命名副本，不覆寫原始檔案。
復原資料可能含敏感內容，請自行決定保留與清除；不要將個人設定、草稿或備份當作公開範例。

記錄檔追蹤為獨立唯讀檢視，可暫停／繼續與跟隨檔尾，不會改寫原始檔。
語系選擇儲存在 EXE 旁 `simple_editor_tool.ini` 的偏好設定中；無寫入權限時請放在可寫入位置。

## 15. 大型檔案與限制

十六進位檢視只讀取可見範圍。超過文字編輯限制時，使用唯讀的大型文字分頁，
每頁最多讀取 256 KiB 原始資料，支援前後頁、第一頁與定位位元組。分頁行號重新起算，
不是整個檔案的行號。Big5／系統編碼只支援可信任的順序邊界。

| 項目 | 目前限制 |
| --- | --- |
| 可編輯文字 | 32 MiB。 |
| 文字／結構比較 | 每側 16 MiB；文字最多 200,000 行。 |
| 全部開啟文件搜尋快照 | 合計 128 MiB。 |
| 尋找結果／Unicode 定位 | 各保留前 100,000 筆，仍可回報完整數量。 |
| 二進位差異畫面 | 前 1,000,000 列；報告可串流完整差異。 |
| 單次位元組轉換／樣式取代 | 64 MiB，依命令另有符合數量限制。 |
| Base64／Hex／UTF-8 轉換 | 輸入 32 MiB、解碼 16 MiB、畫面預覽 64 KiB。 |
| 比較設定預設集 | 32 組、INI 最多 1 MiB。 |
| 語系檔 | 每檔最多 1 MiB、4,096 筆；異常時使用英文備援。 |
| Intel HEX／S-record | 最多 2,000,000 紀錄、64 MiB 解碼資料；BIN 位址跨度最多 256 MiB。 |

Unicode 提示針對既定的不可見與雙向控制字元子集，不是完整的 Unicode 安全檢查器。
來源對齊、範本、EditorConfig、JSON 規則與修補格式也各有明確子集限制，請參閱對應說明。

## 16. 常用快捷鍵與命令列

| 快捷鍵 | 動作 |
| --- | --- |
| Ctrl+O／Ctrl+N／Ctrl+S | 開啟／新增／儲存。 |
| Ctrl+F／Ctrl+H | 尋找／取代。 |
| F3／Shift+F3 | 找下一個／上一個。 |
| Ctrl+Shift+F | 多檔／資料夾搜尋。 |
| Ctrl+G | 文字跳行，十六進位跳位址。 |
| F7／Shift+F7 | 下一個／上一個差異。 |
| Ctrl+Z／Ctrl+Y | 復原／重做。 |
| Ctrl+R／Ctrl+W | 重新載入／關閉分頁。 |
| Ctrl+Tab／Ctrl+Shift+Tab | 下一個／上一個工作區分頁。 |
| 滾輪 | 捲動；只有 Ctrl＋滾輪才縮放。 |
| Ctrl+0 | 重設目前檢視至 100%。 |
| Ctrl+Shift+P／Alt+Left／Alt+Right | 搜尋命令／上一個位置／下一個位置。 |

十六進位、文字與比較各自保留 50%–300% 縮放比例，顯示於狀態列。
可在偏好設定調整支援的快捷鍵；標準編輯／定位保留鍵有衝突檢查。

命令列比較不開啟 GUI，也不讀寫個人 GUI 設定：

```powershell
.\SimpleEditorTool.exe --compare --left "old.bin" --right "new.bin" --mode binary --report "diff.csv"
.\SimpleEditorTool.exe --compare --left "old.cpp" --right "new.cpp" --mode text --report "diff.patch" --format patch
.\SimpleEditorTool.exe --help
```

退出碼：`0` 相同、`1` 有差異、`2` 選項／輸入／輸出失敗、`3` 提交前取消。
`1` 不代表報告失敗。既有報告需明確使用 `--overwrite`；含空白路徑需加引號。
完整模式與範例見 [命令列比較](COMMAND_LINE.md)。

## 17. 檔案總管整合與問題處理

工具選單的 Windows 檔案總管功能可為目前使用者加入／移除右鍵開啟選單，無需系統管理員。
Windows 11 可能將選項放在「顯示其他選項」。移動 EXE 後請在新位置重新登錄；
刪除工具前可先移除自己的選單項目。這不會變更預設檔案關聯。

- 無法解碼文字：確認編碼；二進位請用十六進位，大型文字請用分頁。
- 取代／修改被拒絕：確認唯讀、儲存中、同步鎖與文件版本；不要把過期結果強制套用。
- 合併無法儲存：先解決衝突，或明確選擇允許保留未解決標記。
- 語系仍是英文：確認兩份語系 INI 與 EXE 同資料夾、內容有效，再重新啟動。
- 語系選擇未保存：確認 EXE 旁的設定目錄可寫入，查看是否有設定儲存錯誤提示。
- 同步中途停止：保留日誌與備份，使用預覽後的重試／復原，不要先刪除備份。

此工具參考 WinMerge、Beyond Compare、Notepad++ 等工作流程，不宣稱完整功能相等。
